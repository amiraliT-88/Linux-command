## Overview

A curated single-page reference sheet designed for quick lookup during daily Linux server administration, VPS setup, and system diagnostics:

- **File & Directory Management:** `ls`, `chmod`, `chown`, `find`, `tar`, `grep`, `rsync`
- **Process & Resource Monitoring:** `ps`, `top`, `htop`, `kill`, `systemctl`, `journalctl`
- **Networking & Diagnostics:** `ip`, `netstat`, `curl`, `ss`, `ping`, `ufw`, `iptables`
- **Package Management & System:** `apt`, `yum`, `pacman`, storage inspection (`df`, `du`)
